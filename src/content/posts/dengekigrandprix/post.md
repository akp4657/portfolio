# Dengeki Grand Prix Website

[Dengeki Grand Prix!!](https://www.dengekigrandprix.net/)

Tech Stack: 
- VanillaJS
- CSS
- HTML

::github{repo="akp4657/dengekigrandprix"}

Solo project to promote the Dengeki Grand Prix, an online tournament series I run for the game Dengeki Bunko Fighting Climax: Ignition (The same game featured on [ignite-boost](https://ignite-boost.net/). It's a mobile first design that is meant to easily navigate users to proper resources for the tournament. The site is accompanied by a QR code and business cards that are handed out at tournaments.

Static website hosted on Vercel.
